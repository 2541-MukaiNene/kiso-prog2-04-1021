# 基礎プログラミングⅡ 後期第4回 デモコード

2026-10-21の授業で、スライドに出てきたコードをまとめたものです。

**使い方：** 各ファイルの先頭に【種類】【内容】【まずやること】【やってみよう】が書いてあります。そのまま実行するだけでなく、**値を変える → 結果を予想する → 実行して確かめる** を繰り返してください。
「作成」のファイルは、`/* ← ここを直す */` などのコメントがある行を自分で書き換えて完成させます。

## ファイル

| ファイル | 種類 | 内容 |
|---|---|---|
| 01-int-division.c | 確認 | int同士の割り算（7 / 2）が切り捨てになることを確かめる |
| 02-type-cast.c | 確認 | 変数でも、intのままだと割り算が切り捨てになる。キャストすると小数になる |
| 03-truncate-negative.c | 確認 | (int)キャストは四捨五入ではなく、0方向への切り捨てであることを確かめる |
| 04-round-trick.c | **作成** | (int)(x + 0.5) で四捨五入ができる。負の数でも正しく動くように修正する |
| 05-ariane-cast-demo.c | 確認 | Ariane 5の事故を再現：64bitの小数を16bitの整数にキャストして範囲を超える |
| 06-clamp-cast.c | **作成** | 明るさのクランプ処理（キャスト版）に、下限（0未満）のクランプを追加する |
| 07-average-exercise.c | **作成** | 平均点が整数の割り算で切り捨てられている。小数まで正しく表示するように直す |
| 08-led-shift.c | 確認＋改造 | 前回(#3)の持ち越し：`1 << n` でn番目のビットだけを操作し、LEDの点灯・消灯に見立てて表示する |

- **確認**：まずそのまま実行し、ファイル先頭の【まずやること】に書いた表示になるか確かめる。そのあと【やってみよう】で値を変えて試す
- **作成**：コメントで示された行を自分で書き換えて完成させる
- **確認＋改造**：実行して確かめたあと、コードを書き足す

## 実行方法

```
cc -Wall -std=c11 -o 01-int-division 01-int-division.c
./01-int-division
```

## 注意

- 05-ariane-cast-demo.c の `short` へのキャストの結果は、多くの環境での動作です。C言語の規格では、整数型どうしの範囲外への変換は実装依存のため、環境によって結果が変わることがあります。
