# 基礎プログラミングⅡ 後期第4回 デモコード

2026-10-21の授業で、スライドに出てきたコードをまとめたものです。

## ファイル

| ファイル | 内容 |
|---|---|
| 01-int-division.c | int同士の割り算（7 / 2）が切り捨てになることを確かめる |
| 02-truncate-negative.c | (int)キャストは四捨五入ではなく、0方向への切り捨てであることを確かめる |
| 03-type-cast.c | 変数でも、intのままだと割り算が切り捨てになる。キャストすると小数になる |
| 04-round-trick.c | (int)(x + 0.5) で四捨五入ができる。ただし負の数では、そのままだとうまくいかない |
| 05-ariane-cast-demo.c | Ariane 5の事故を再現：64bitの小数を16bitの整数にキャストして範囲を超える |
| 06-clamp-cast.c | 第2回の「明るさのクランプ」を、キャストを使って書き直す |
| 07-average-exercise.c | 基本演習：平均点が整数の割り算で切り捨てられている。小数まで正しく表示するように直す |
| 08-led-shift.c | 前回(#3)の持ち越し：`1 << n` でn番目のビットだけを操作し、LEDの点灯・消灯に見立てて表示する |

## 実行方法

```
cc -Wall -std=c11 -o 01-int-division 01-int-division.c
./01-int-division
```

## 注意

- 05-ariane-cast-demo.c の `short` へのキャストの結果は、多くの環境での動作です。C言語の規格では、整数型どうしの範囲外への変換は実装依存のため、環境によって結果が変わることがあります。
